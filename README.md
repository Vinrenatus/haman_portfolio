## 📁 Project Structure

This repository contains a comprehensive portfolio application with:

- 🌐 **Frontend**: React.js application in `/portfolio/frontend/`
- 🐍 **Backend**: Python Flask API in `/portfolio/backend/`
- 🐳 **Containerization**: Docker and docker-compose support
- 🔄 **CI/CD**: Multiple pipeline configurations (GitHub Actions, Jenkins, GitLab CI)
- 🔐 **Admin Dashboard**: Full content management system

## 🚀 Quick Start

For detailed setup instructions, please refer to the specific README in the `/portfolio/` directory.

### 🏗️ Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/MurayaSoftTouch/haman_portfolio.git
   cd haman_portfolio
   ```

2. Navigate to the portfolio directory:
   ```bash
   cd portfolio
   ```

3. Follow the setup instructions in `/portfolio/README.md`
